# mg-content

Content operating repository for `mehulgohil.com`.

## Structure
- `CONTEXT.md`: Source of truth for positioning, ICP, offer model, and messaging constraints
- `prompts/`: Prompt systems for article generation, optimization, planning, and pruning
- `services/`: Curated service URL indexes for service-page linking and offer alignment
- `articles/`: Curated article and case-study URL indexes for internal linking and topic de-duplication

## Usage Notes
- Use URL index files before creating new topics to avoid duplicates.
- Update URL index files whenever new pages/posts are published.
- Keep all prompts aligned with `CONTEXT.md`.
